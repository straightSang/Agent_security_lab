# v1 — 일자별 구조 (보존용)

Day 1 ~ Day 9의 원본 폴더다. **읽기 전용 아카이브이며 더 이상 수정하지 않는다.**

## 왜 여기로 옮겼나

이 구조는 매일 전날 폴더를 통째로 복사하는 방식이었다. 그래서 Day9 폴더의
파일 409개 중 203개가 Day8과 같은 이름의 사본이었다. 어느 것이 최신인지
파일 트리만 봐서는 알 수 없고, 한 곳을 고치면 나머지 사본이 조용히 낡는다.

v2에서 단일 트리로 통합하면서 최상위를 비웠다. 다만 각 Day의 실험 보고서와
trace는 그 시점의 관측 기록이므로 그대로 남긴다.

## 원본 그대로 보고 싶다면

```bash
git checkout v1.0
```

`v1.0` 태그가 개편 직전 상태를 가리킨다. GitHub Releases에서도 받을 수 있다.

저장소 최상위의 `src/`, `tests/`다. 변경 내역은 `docs/CHANGELOG.md` 참조.
