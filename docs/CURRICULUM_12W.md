## W1~W2 상세 절차

상위 표는 60일 전체 지도라서 한 칸이 두세 줄이다. 그 압축 때문에 "단일 트리를 읽는다",
"회귀 스위트" 같은 줄임말이 설명 없이 남아 있었다.

**W1 D1 ~ W2 D5 10일치는 `W1W2_실행가이드.docx`에 절차 수준까지 풀어 썼다.**
하루가 여섯 부분으로 되어 있다.

| 부분 | 내용 |
|---|---|
| 오늘 한 문장 | 그날 끝났을 때 말할 수 있어야 하는 것 |
| 왜 하는가 | 이 하루가 없으면 무엇이 무너지는지 |
| 오늘의 용어 | 그날 처음 나오는 말만 |
| 절차 | 실제 명령·파일 이름·줄 번호 |
| 완료 확인 | 체크박스. 전부 채워야 다음 날로 |
| 막히면 | 자주 걸리는 지점과 대처 |

W3 이후는 그 주에 들어갈 때 같은 형식으로 작성한다. 미리 다 쓰면 실제 진행과 어긋난다.
